# 自选收藏分组设计

## 需求

- 币种收藏列表，支持分组管理。
- 每个分组里的 token 相互独立：同一 token 可出现在多个分组。
- 可快速把收藏币种添加到大屏格子。

## 数据模型

```ts
type WatchGroup = {
  id: string;        // 唯一 id
  name: string;      // 分组名
  tokens: string[];  // 币种交易对，如 "BTCUSDT"（现货）或 "BTCUSDT.P"（USDT 永续合约）；同一 token 可出现在任意多个分组
};
```

存储：`WatchGroup[]` 持久化到本地（见 docs/plans/persistence.md）。

## 关键设计

- **token 跨组独立**：分组之间无互斥约束，添加 / 删除只影响当前分组。
- **点击切换格子**：点击侧栏中的币种，当前激活格子（高亮边框）的 symbol 立即更新为该币种，实现快速盯盘切换。
- **支持现货 + 永续合约**：搜索框同时列出 Binance USDT 现货（`BTCUSDT`）与 USDT-M 永续合约（`BTCUSDT.P`，显示为 `BTC/USDT 永续`），都可加入自选分组并在网格打开；`BinanceProvider` 对 `.P` 交易对走 fapi 数据源（见 `playground/binanceMarkets.ts`）。
## UI 形态（当前原型）

- **侧栏占满完整左侧高度**（上自选、下设置），不再是顶部/角落的小面板。
- 侧栏结构：
  - 顶部：**「自选 / 功能模块」tab 标签页**，功能模块独立成 tab，不再混在自选分组列表里。
  - 「自选」tab：自选分组列表 + 每组 token 列表（每个 token 显示「最后价 / 24h 涨跌幅」）。
  - 分组列表**按名称宽度动态换行**（短名称一行多个、长名称占整行截断），不是每条占一整行。
  - 底部：「⚙ 设置」按钮，打开设置弹窗。
  - 收起按钮贴在侧栏右边框中部（与展开按钮同一位置），展开按钮在折叠后出现在同一位置。
- **设置弹窗**：左侧竖排 tab（自选管理 / EMA 配置 / 告警）+ 右侧内容区；EMA 配置为全局生效（见 docs/plans/persistence.md）。
- 支持新建 / 重命名 / 删除分组，增删 token。
- 支持搜索币种（可通过 `BinanceProvider.listSymbols` 或预置热门列表）。搜索下拉交互：
  - 点击结果行主体 → 直接在网格打开该币种（不会自动加入自选）。
  - 点击行右侧星标按钮（☆ / ★）→ 把该币种加入当前自选分组；已在该分组的显示为 ★。

## 持久化

收藏分组数据存入本地存储（原型 localStorage `vela-dashboard-groups-v2`，桌面版迁移 IndexedDB），变更即保存；启动时加载。
