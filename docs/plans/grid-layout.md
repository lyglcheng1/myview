# 多格网格布局设计

## 需求

- 一屏同时展示多个币种 K 线（监控大屏）。
- 每个格子独立配置：币种、周期（`1m 5m 10m 15m 30m 1h 4h 8h 12h 1d 1w 1M`）。
- 支持切换预设网格布局（4 格、8 格等）。
- 深色盯盘主题。
- 布局配置本地持久化保存。

## 方案：VelaWorkspace layout

VelaWorkspace 原生支持多图网格：`layout` 选项接受 `'2h' | '4' | '8' | false` 等预设。以 workspace 为基底：

- 每个格子是一个独立 chart cell，拥有独立 symbol / timeframe。
- 共享一个顶栏与状态栏（原型中已隐藏，打造"大屏"形态）。

## 页面结构（当前原型）

整体为「左侧自选栏 + 右侧图表区」的两栏布局：

```
┌─────────┬──────────────────────────────┐
│ 自选栏   │  图表网格（N 格，大屏主区域）     │
│ （占满    │                              │
│  左侧）  │                              │
│  ⚙ 设置  │                              │
├─────────┴──────────────────────────────┤
│ 右下角：Pine 脚本编辑区（可收起 / 高度可拖）  │
└─────────────────────────────────────────┘
```

- 自选栏占满完整左侧高度，底部为「⚙ 设置」入口。
- 图表网格是主区域，右下角叠加 Pine 脚本编辑区（dock，可收起/展开，顶部分割线可拖动调高度）。
- 设置弹窗为「左侧竖排 tab + 右侧内容」的模态框。

## 每格独立配置

- 每个格子右上角自带**独立周期下拉**（不再统一放顶部），可单独切换该格周期。
- 切换预设布局时，保留每格已配置的币种，映射到新布局的格子位置。
- 点击自选栏中的币种，会替换当前激活格子的 symbol（激活格子高亮边框）。

## 分栏布局（自定义，playground 原型已实现）

右上角布局弹出框提供「分栏布局」，支持非对称网格：

- **方向**：左右分栏 / 上下分栏。
- **主区**：主侧行数 / 列数（1×1、1×2、2×1、2×2 等）。
- **次区**：次侧行数 / 列数，次区短边自动均匀拉伸填满剩余空间。
- 点击「应用」后切换为自定义布局；再次打开弹出框可看到当前配置。

实现：

- 纯逻辑在 `playground/splitLayout.ts`：`layoutForSplit({ direction, primary, secondary })` 生成 Vela `LayoutDefinition`（grid-template-areas + spans），注册为 `custom-split` 布局，已单元测试。
- 通过公开 `registerLayout` 扩展，不 fork 库内部实现。

## 布局持久化

- 布局配置（格子数、每格币种 / 周期）序列化后存入本地存储（见 docs/plans/persistence.md）。
- **默认布局固定为 1×1 单格子（BTCUSDT / 15m）**；启动时即此状态，下拉框固定显示「默认布局（1格）」。
- 「保存布局」会把**当前网格结构（layout id ＋ 完整网格定义）＋ 每格币种 / 周期**存为一个命名方案；从顶栏下拉框选择方案时，**先切换网格结构，再逐格恢复币种与周期**。自定义 / 分栏布局的完整定义随方案保存，应用时重新注册再切换，因此刷新页面后仍能恢复（分栏布局只在「应用分栏」后才注册，刷新后不复存在）。
- 早期缺少结构信息的旧方案（仅保存了每格内容）只会恢复每格内容（应用时会提示）；**把它们重新保存一次**即可带上网格结构。
- 下拉框的中性占位项是「— 选择布局 —」，与「默认布局（1格）」分离：「默认布局（1格）」是**真实可切换的布局**（独立 value），选中它即回到 1×1 默认格子（BTCUSDT / 15m）。这样从其他布局切回默认时，下拉值始终发生变化，`change` 必然触发。
- 选择方案后下拉框**固定显示该方案名称**，让用户知道当前生效的是哪一套；一旦网格被手动改动（换币、改周期、切换预设 / 分栏结构），下拉框回到中性占位项「— 选择布局 —」，此时再次选择同一方案仍会触发应用。
- 下拉框选中某个已保存方案时显示「重命名」和「删除」按钮：可修改方案名称（内联输入，回车确认），也可删除该方案（有确认提示）。

## 深色主题

- workspace 使用 `theme: 'dark'`。
- 隐藏非盯盘必需的 UI 元素，最大化图表可视区域。

## 交互

- 搜索框输入即过滤币种：点击结果行在网格打开该币种；行右侧星标按钮加入当前自选分组（见 docs/plans/watchlist.md）。
